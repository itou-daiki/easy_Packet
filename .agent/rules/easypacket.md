# easyPacket 作業ルール

## このプロジェクトの性質

山梨大学「情報ネットワーク演習」で使う**授業用の学習教材**。一般的なWebアプリではない。
判断に迷ったら次の優先順位で決めること。

1. **授業が止まらないこと** — 学内ネットワーク・プロキシ・オフラインでも必ず動く
2. **教える内容が正しいこと** — 生徒が覚えてしまう情報に誤りがあってはならない
3. **誰でも使えること** — 端末・画面サイズ・支援技術を問わない
4. 見た目の洗練・コードの美しさ

## 着手前に必ず読むファイル

- `docs/00_調査レポート.md` — 不具合20件（F-1〜F-20）。実測値と該当行つき
- `docs/02_内容点検.md` — 教材内容の誤り9件（C-1〜C-9）。dig / whois で裏取り済み
- `docs/01_実装計画_Antigravity.md` — Phase 0〜9 と各フェーズの検証条件

## 禁止事項

- **外部APIに依存する実装を新たに足さない。** オンライン機能を足す場合は必ず
  「既定オフライン＋任意でライブ」の二層にし、ライブが失敗しても授業が続くようにする。
- **ダミーIPは必ず予約領域から選ぶ。** RFC 5737（`192.0.2.0/24`, `198.51.100.0/24`,
  `203.0.113.0/24`）、RFC 1918、RFC 6598。実在組織に割り当て済みのグローバルIPを
  「架空のルータ」として使わない。**ランダム生成は禁止**（現状 99.4% が実配当空間に当たる）。
- **`innerHTML` を使わない。** `textContent` と `document.createElement` を使う。
- **`canvas.width` / `canvas.height` を、その canvas 自身の測定値から算出しない。**
  必ず親要素を測る。canvas の CSS 幅は CSS 側で固定する。（F-1 の再発防止）
- **非同期処理の状態フラグは必ず `try/finally` で戻す。**（F-13 の再発防止）
- 破壊的な git 操作（`push --force`, `reset --hard`, ブランチ削除）を勝手に行わない。
- 既存の日本語UIテキストの語調を変えない（です・ます調、絵文字付き見出し）。
- フレームワーク・ビルドツールを導入しない。素の HTML/CSS/JS のまま直す。

## 進め方

1. 着手前に**実行計画の概要を提示して承認を得る**。いきなり編集を始めない。
2. 1フェーズ＝1コミット。フェーズをまたいで混ぜない。
3. 各フェーズの完了条件を**実測で**満たしてから次へ進む。「直したはず」ではなく
   数値かスクリーンショットを出す。
4. 完了報告には実行前後のスクリーンショットと検証コマンドの出力を添える。

## 動作確認

```bash
python3 -m http.server 8777
# http://127.0.0.1:8777/index.html
```

`file://` で直接開いても動くことを必ず確認する（`fetch()` がCORSで失敗する環境）。
